حاسبة جمعياتي - مشروع Android Studio

المميزات:
- بيانات جمعيتي بسام وشيماء من ملف Excel الأصلي، مع الدفعات وحالات الدفع كما وردت.
- إضافة جمعية جديدة بالاسم ودورية الدفع: يومي أو أسبوعي أو شهري.
- إنشاء 20 موعد دفع تلقائياً بدءاً من تاريخ البداية الذي تختاره.
- متابعة حالة كل دفعة وإجمالي المدفوع والمتبقي للجمعيات التي لها مبلغ دفعة.
- حفظ البيانات محلياً على نفس الهاتف.

إنشاء APK:
1) افتح مجلد المشروع Hisab_Gam3eyaty_Android في Android Studio.
2) انتظر Gradle Sync، وثبّت Android SDK Platform 35 إذا طُلب.
3) من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
4) ستجد الملف داخل app/build/outputs/apk/debug/app-debug.apk

ملاحظة: هذا تسليم مشروع Android جاهز للبناء وليس ملف APK موقّعاً. بيئة التنفيذ الحالية لا تحتوي على Android SDK أو Gradle، لذلك لم أتمكن من تجميع APK هنا.
